# Stark Commander 🚀

Stark Commander is a web-based remote control interface for your laptop. Designed to run on your local network, it allows you to execute system-level commands—such as volume control, media playback, sleep, and app launching—directly from your phone or another device without needing a chat interface.

## ✨ Features
* **Remote System Power Control:** Easily trigger sleep, restart, or shutdown commands remotely.
* **Media & Volume Management:** Play, pause, mute, and adjust the volume of your laptop's media.
* **Application Launcher:** Quickly open frequently used applications or scripts.
* **Local Network Access:** Runs over your local Wi-Fi, keeping interactions fast and secure without exposing your machine to the public internet.
* **Minimalist UI:** Clean, button-driven interface designed for quick taps on a mobile screen.

## 🛠️ Tech Stack
* **Frontend:** React / HTML & CSS (Adjust based on your exact frontend)
* **Backend:** Python (Flask) 
* **System Integration:** Python `os` and `subprocess` libraries for executing local Ubuntu/Linux shell commands.

## 📋 Prerequisites
* **Python 3.x** installed on the host laptop.
* Both the host laptop and the remote device (e.g., your smartphone) must be connected to the **same local Wi-Fi network**.
